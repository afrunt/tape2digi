# tape2digi v0.0.3

Small things that make every tape easier: a level meter that shows where to aim, a warning when no sound arrives, recording from the keyboard and folder pickers that remember where you were.

## New

- **Target zone on the level meter**: the recorder meter has a dB scale (-40 to 0 dB) and a marked zone from -12 to -6 dB. Set the deck volume so the loudest parts land there.
- **No signal warning**: while recording, a **No signal** note appears next to the timer when every channel stays below -50 dBFS for 10 s. Check the input and the deck volume; the note disappears as soon as sound returns.
- **Recording shortcuts**: `Cmd/Ctrl+R` records the next empty side, `Space` pauses or resumes, `Esc` stops. The keys are ignored while you type in a field or a dialog is open.
- **Remembered folders**: the export folder picker opens in the last export folder, and the new, open and Save As pickers open where you last chose a project folder.
- **`Home` / `End`** in the side editor move the playhead to the start / end of the side.

## Improved

- Disabled **Record** and **Edit** buttons explain in their tooltip why they are unavailable.
- The project name field on the start screen and the Artist field in track lookup are ready for typing when they open.
- `Enter` in the **Save As…** name field saves the copy.
- **Fit** in the editor and the track player has a tooltip.
- The README starts with a friendly guide for everyone who wants to digitise their tapes; technical details moved to the end.

## Upgrading from 0.0.2

- Projects and settings from 0.0.2 open as they are.
- `settings.json` gains `lastExportDir` and `lastProjectsDir`; they are filled after your first pick.

## Notes

- Hardware checks (capture, monitor, long recordings) were done on macOS arm64; other platforms are compile-verified only.
- macOS asks for microphone permission on first run. Builds are not code-signed, so the OS may warn on first launch.
- Linux needs GTK3 and WebKit2GTK 4.1 installed.
- Settings and local data live in `~/.tape2digi/`. The optional track lookup is the only network access.

See the [README](https://github.com/afrunt/tape2digi#readme) for usage and build instructions.

# tape2digi v0.0.3

Дрібниці, що спрощують роботу з кожною касетою: індикатор рівня показує, куди цілитися, програма попереджає, коли звук не надходить, запис керується з клавіатури, а вибір теки пам'ятає, де ви були.

## Нове

- **Цільова зона на індикаторі рівня**: індикатор запису має шкалу в дБ (від -40 до 0 дБ) і позначену зону від -12 до -6 дБ. Налаштуйте гучність деки так, щоб найгучніші місця потрапляли в неї.
- **Попередження про відсутність сигналу**: під час запису біля таймера з'являється позначка **No signal**, якщо всі канали 10 с тихіші за -50 dBFS. Перевірте вхід і гучність деки; позначка зникає, щойно звук повертається.
- **Клавіші запису**: `Cmd/Ctrl+R` записує наступну порожню сторону, `Space` ставить на паузу або продовжує, `Esc` зупиняє. Клавіші не діють, коли ви вводите текст у полі або відкрито діалог.
- **Запам'ятовані теки**: вибір теки для експорту відкривається в останній теці експорту, а вибір для нового проєкту, відкриття й Save As — там, де ви востаннє обирали теку проєкту.
- **`Home` / `End`** у редакторі сторони переносять позицію відтворення на початок / кінець сторони.

## Покращено

- Вимкнені кнопки **Record** і **Edit** пояснюють у підказці, чому вони недоступні.
- Поле назви проєкту на стартовому екрані та поле Artist у пошуку треків одразу готові до введення.
- `Enter` у полі назви **Save As…** зберігає копію.
- Кнопка **Fit** у редакторі та програвачі треків має підказку.
- README починається з дружнього посібника для всіх, хто хоче оцифрувати свої касети; технічні подробиці перенесено в кінець.

## Оновлення з 0.0.2

- Проєкти й налаштування з 0.0.2 відкриваються без змін.
- У `settings.json` з'являються `lastExportDir` і `lastProjectsDir`; вони заповнюються після першого вибору теки.

## Завантаження

Файли для macOS, Windows і Linux (amd64 та arm64) наведено в таблиці вище.

## Примітки

- Апаратні перевірки (захоплення, монітор, довгі записи) виконано на macOS arm64; на інших платформах лише перевірено компіляцію.
- macOS запитує дозвіл на мікрофон при першому запуску. Збірки не підписані, тож ОС може попередити під час першого запуску.
- Для Linux потрібні GTK3 та WebKit2GTK 4.1.
- Налаштування та локальні дані зберігаються в `~/.tape2digi/`. Необов'язковий онлайн-пошук треків — єдиний доступ до мережі.

Докладніше про використання та збірку див. у [README](https://github.com/afrunt/tape2digi#readme).
